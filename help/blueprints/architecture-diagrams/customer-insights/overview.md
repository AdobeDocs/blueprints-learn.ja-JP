# 顧客インサイト

Adobe Customer Journey Analyticsは、複数のインタラクションチャネルとソースからの顧客データと行動を統合し、カスタマーインタラクションのジャーニーベースのビューを作成します。 このカテゴリでは、コア CJA、B2B CJAの派生、Real-Time CDPへのオーディエンス共有、CJAとJourney Optimizerの統合に関するアーキテクチャのリファレンスを提供します。

コア [Adobe Customer Journey Analytics](cja.md) アーキテクチャには、B2B分析とCJA オーディエンスのReal-Time CDPへの公開のための派生が含まれています。 [Adobe Customer Journey AnalyticsとAdobe Journey Optimizerの統合](cja-ajo-integration.md) アーキテクチャでは、キャンペーンとジャーニーのインサイトについて説明します。

## Customer Journey Analytics ユースケース

一般的なユースケースを次に示します。

* オーディエンスの作成と Real-time Customer Data Platform への公開
* トップ／ボトムコンバージョンパス
* チャネルのエンゲージメントとコンバージョン
* 閲覧数上位のコンテンツ
* 上位のカテゴリおよび製品
* コンバージョンおよびエンゲージメント向上につながったキャンペーン
* セルフサービスエクスペリエンスを最適化するためのツール使用状況分析

Customer Journey Analyticsのユースケースの完全なリストについては、[Customer Journey Analyticsのユースケースに関するドキュメント ](https://experienceleague.adobe.com/docs/analytics-platform/using/cja-usecases/cja-usecases.html?lang=ja)を参照してください。
