# セットアップ

AEP Foundations ラボを開始する前に、以下の設定手順を完了してください。 どのステップが必要かは、このブートキャンプの進め方によって異なります。

## 要件とアクセス

- API呼び出しを行うラボを開始する前に、[Postmanの設定](#postman-setup)を完了してください。
- [webhook.site](https://webhook.site/)へのアクセスは、イベントを外部宛先に送信するEdge アクティベーションおよびオーディエンスアクティベーションラボに必要です。
- LID手法の演習では、ワークブックを印刷するプリンターと、それを完成させるペンまたは鉛筆が必要です。 [LID手法の前提条件](lid-methodology/prerequisites.md)を参照してください。

## サンドボックス設定

>[!NOTE]
>
>ライブトレーニングコースやイベントに参加されている場合は、サンドボックスが既にデプロイされています。このセクションをスキップして、以下のPostman設定に直接移動してください。

ラボアセットがデプロイされた作業用サンドボックスがまだ存在しない場合は、次の手順を実行します。

- [Developer Console設定](sandbox-setup/developer-console-setup.md)
- [デプロイメント手順](sandbox-setup/deployment-instructions.md)

## Postmanの設定

サンドボックスのプロビジョニング方法に関係なく、このコースのラボにはPostmanが必要です。 続行する前に、次の項目を完了してください。

- [Postman インストール](postman-setup/postman-installation.md)
- [環境ファイル](postman-setup/environment-file.md)
- [API コレクション](postman-setup/api-collection.md)
- [サンドボックスアクセス](postman-setup/sandbox-access.md)
- [アクセストークン](postman-setup/access-token.md)
