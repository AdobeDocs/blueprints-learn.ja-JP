# 講義

XDM （Experience Data Model）は、Adobeを使用して、さまざまなシステムをまたいで顧客体験データを整理するための標準化されたフレームワークです。 web サイト、アプリ、CRMなど、さまざまなソースからのデータを一貫性のある方法で構造化することで、リアルタイムのデータを容易に統合、分析、活用できます。 この一貫性は、正確な顧客プロファイルを構築し、パーソナライズされた体験を実現して、Adobe Experience Platform全体でAI主導のインサイトをサポートするうえで不可欠です。



## XDMでの構築

このビデオでは、クラスとフィールドグループでスキーマを構成する方法、ドット表記法のパスの仕組み、ERDからマッピングシートを作成する方法など、リアルタイム顧客プロファイルがXDMでどのように構築されているかを説明します。
