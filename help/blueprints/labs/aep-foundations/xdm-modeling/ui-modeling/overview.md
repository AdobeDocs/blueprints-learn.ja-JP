# UI モデリング

## ソースのXDMへのマッピング

紙に書いたものを翻訳する経験を積み、XDM **標準**&#x200B;のオブジェクトとフィールドを見つけてマッピングする方法と、**カスタム**&#x200B;のオブジェクトとフィールドを作成する方法を学びます。

この記事では、スクラムオブスクラムの概要、利点、導入方法を解説します。

- エクスペリエンスデータモデルの概念を実際に確認できるUI知識
- **XDM フィールドグループ**&#x200B;のコンテキストでオブジェクトとフィールドがどのように定義されているかを理解する
- スキーマ UIを使用してXDM標準フィールドグループを探索する方法について説明します



## UI経由でのXDMの作成

LID手法を使用して作成したスキーマを活用するConnection 5G顧客アカウントスキーマの構築を実践的に行います

この記事では、スクラムオブスクラムの概要、利点、導入方法を解説します。

- スキーマ構成UI全体に関する基本的な理解
- XDM標準フィールドグループをスキーマに追加する方法について説明します
- XDM標準フィールドグループから不要なフィールドを削除する方法について説明します
- スキーマでカスタムフィールドグループを作成し、使用できる
- スキーマの開発中に頻繁に保存する方法を学ぶ😄
- 列挙と推奨値の違いを理解する



## プロファイル用の設定

ID マーキングからルックアップスキーマのリレーションの確立まで、リアルタイム顧客プロファイルで使用するスキーマを設定するために必要な手順を説明します。

この記事では、スクラムオブスクラムの概要、利点、導入方法を解説します。

- フィールドをIDまたはプライマリ IDとしてマークできる
- 2つのスキーマ間の関係を構築する
- プロファイルを有効にする前にスキーマを&#x200B;**テスト**&#x200B;する理由を理解する
- **結合スキーマ**&#x200B;について理解し、実際の動作を視覚的に確認する
