# 注文の読み込み

## ラボの概要

このラボでは、複雑なデータ変換とJSON データ処理について説明します。

## 学習目標

このラボの重要なポイントは何ですか？

- ネストされたJSON データのバッチ取り込みについて
- オブジェクトコピーをコンセプトとして使用すると、複雑な非XDM フィールドとXDM フィールド間のフィールドマッピングを簡素化できます。
