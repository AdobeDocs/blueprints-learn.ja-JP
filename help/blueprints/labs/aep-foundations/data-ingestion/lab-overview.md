# ラボの概要

## 目標

ラボの目的は、データ収集に関する現実的な課題に対処するための準備を整えることです。 この理解により、本番環境へのデータ実装を管理し、チームを適切に管理できるようになります。 理論が魅力的であるのと同じくらい、私たちは問題が発生したときにデバッグに時間を費やし、ツールで見ているものをこのブートキャンプで教えられたより広範な概念に結び付けます。



## 何を期待するか

君の集中力が必要だ。 その理由は次のとおりです。データは、これからおこなうあらゆる実装の基盤となります。

データの問題は簡単ではありません。 データは整理されておらず、不完全で、分散しており、必要なときにシステムに取り込むのは困難です。 これらのラボは、これらのシナリオを味わえるように設計されています。

これらの次のラボセットは、システムの内部に触れるので、注意と献身が必要です。 あなたが一括ですべての概念を吸収することは期待されていませんので、ラボであなたの道を見つけるために時間をかけてください。



## 一言で言えばシラバス

ソーススキーマがあり、XDMでターゲットスキーマを定義しているので、マッピングを介して2つのスキーマを接続する必要があります。 このプロセスでは、フィールドマッピングによるフィールドが必要なので、いくつかの一般的な落とし穴を認識しながら、プロセスをスピードアップするいくつかのテクニックを学ぶ必要があります。

- パススルーマッピングについて
- AI/ML生成パススルーマッピングの修正
- ソースデータのプレビューを使用して、データ品質の問題を確認する

スキーママッピングを設定したら、作業をテストし、エラーと警告をデバッグする必要があります。

- データフロー実行のスケジュール
- プロファイルのデータセットをマーク
- 必須フィールドの値の欠落から発生するエラーを処理します
- データ型の不一致エラーから生じるエラーに対処する
- データ取り込みエラーに対処し、そのような障害から回復します
- テストデータを反復的に使用して、包括的なマッピングセットを生成します。
- 正常に取り込まれたデータを検証し、検証します。

上記の概念は、関係データ取り込みシナリオと非関係データ取り込みシナリオで学習します。
