# ユースケース #2 - アップセル

## 概要

このビデオでは、有料およびダイレクトメールチャネルを通じてアクティベーションするために、データを使用する多くの顧客をターゲットとするアップセルユースケースに取り組む方法を説明します。

>[!VIDEO](https://video.tv.adobe.com/v/3459487/?quality=12&learn=on)



**ユースケース定義**

過去6か月間の合計請求データ使用量が140 GBを超え、6か月間平均の合計請求データを持つすべての顧客を検索します。 月間データ使用量が>=20GBで、最終的な電話プランを持っていないユーザー。

Facebook / Googleおよびダイレクトメールチャネルでアクティベートします。

ダイレクトメールパーソナライゼーションフィールド：

- 名前→挨拶に使用されます
- 郵送先住所→郵送用に使用
- プラン名→メーリングステートメントに使用されます（例：「Eric、今すぐ究極のプランにアップグレードしてください」）。

## アプローチ

このユースケースでは、2つのオプションを評価します。

- オプション#1 （集約にオーディエンスを使用）
  - これにより、オーディエンスが集計を行い
    - 請求データ使用量の合計>140 GB （過去6か月間）
    - 請求データ使用率は平均20 GBを超えています（過去6か月間）
    - 請求データの使用率は高いが、Ultimateプランはない
- オプション #2 （事前集計を使用）
  - これにより、データをプロファイルに配置する前に行われた集計が使用されます
    - 請求データの使用率は高いがUltimate プランなし（Agg）
