# イベント転送の設定

イベント転送はEdge上に構築され、一連のルールを作成して任意のエンドポイントにイベントを送信することができます。

このステップでは、Edgeに送信するすべてのイベントをWebhookに転送します。 Webhookはサードパーティのプロキシとして機能し、何が起こっているかを確認できます。

これを設定するには、次のように設定します。

- 転送する内容と場所を決定するために必要なすべての拡張機能、データ要素、およびルールを含むプロパティ
  - 受信イベントを参照するか、必要に応じて複数の個々のコンポーネントに解析するデータ要素
  - 転送する内容に関する条件を追加するルール、ペイロードを変換する場所、およびペイロードを送信する場所
- どのサービスを利用するかを設定するデータストリーム（例：イベント転送とAEP）
  - これらのデータストリームに送信されたデータは、設定されたサービスに従ってアクションを実行できます（例：イベントの転送とデータセットへのデータ送信）
