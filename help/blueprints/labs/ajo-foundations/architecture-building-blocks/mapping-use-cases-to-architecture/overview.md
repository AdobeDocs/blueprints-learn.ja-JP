# ユースケースのアーキテクチャへの割り当て

## 学習目標

このラボの終わりまでに、次のことが可能になります。

- 構造化された意思決定フレームワークを適用して、実際のマーケティングのユースケースを評価する
- 各ユースケースをサポートするために必要なAJOのアーキテクチャコンポーネントを特定します
- 適切なオーケストレーションエンジン（キャンペーンやジャーニーのオーケストレーション）を選択し、レコメンデーションの正当性を判断します
- Connection 5Gの3つのユースケースすべてについて正しいアーキテクチャ決定を説明し、それぞれのユースケースを導いたシグナルを明確にします

準備ができたら、ラボの手順については、ビデオを参照してください。
