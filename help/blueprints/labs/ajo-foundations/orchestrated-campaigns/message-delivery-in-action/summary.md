# 概要

このラボでは、次のアクティビティを実行しました。

- オーケストレーションされたキャンペーンを構築
- 「オーディエンスを構築」アクティビティを使用して、基本プランメンバーのオーディエンスを構築
- オーディエンスをフォークして2つのブランチを作成し、メールチャネル `Profile-Email`と`Relational-Email`をそれぞれ使用してメッセージを送信しました
- 設定された2つのメールチャネル間の動作の違いを確認するために、キャンペーンをテストしました





>[!TIP]
>
>**これを読んでいる場合は、ラボの最後にいることを意味します。**
>
>**続行しない、移動しない、200 ドルを収集しない**
