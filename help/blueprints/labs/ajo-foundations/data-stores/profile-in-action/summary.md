# 概要

このラボでは、データストリームを設定し、Postmanを使用してEdge Networkにシミュレートされたweb イベントを送信して、Adobe Experience Platformでのデータフローを確認しました。

プロファイルが作成され、リアルタイムプロファイルのセグメントに適合していることを確認することで、イベントが複数のプラットフォームサービスによって処理されたことを検証しました。 また、プロファイルがEdgeに存在することを確認し、イベントがデータレイクに保存されていることを確認し、スケジュールされたバッチ更新プロセスにより、プロファイルがまだプロファイルスナップショットデータセットに表示されていないことを確認しました。

これらのステップでは、Adobe Experience PlatformのEdge、リアルタイムプロファイル、データレイクの各レイヤーを通して、イベントがどのように移動するかをデモしました。



&#x200B;> [!TIP]
>
>**これを読んでいる場合は、ラボの最後にいることを意味します。**
>
>**続行しない、移動しない、200 ドルを収集しない**
