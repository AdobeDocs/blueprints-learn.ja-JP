# プロファイルの実際

## 前提条件

>[!WARNING]
>
>以下のラボは、このラボを開始する前に完了している必要があります

- [Postman インストール](../../postman-setup/postman-installation.md)

これらのラボを完了していない場合は、続行する前に今すぐそれを行ってください。

## ラボの概要

このビデオでは、このラボでEdge NetworkからAdobe Experience Platformへのweb ページ訪問をシミュレートする方法と、結果として得られるプロファイル、セグメントの選定、データレイクイベントを検証する方法について説明します。

>[!VIDEO](https://video.tv.adobe.com/v/3491061/)

## 学習目標

この演習では、Edge ソースからAdobe Experience PlatformへのWeb ページ訪問をシミュレートします。 このラボを受講した後、何を持って帰るべきですか？

- Adobe Experience Platformでのデータストリームの作成と設定
- Postmanを使用してEdge Networkにテスト web イベントを送信する
- リアルタイムプロファイルでのプロファイル作成とセグメントの選定の検証
- プロファイルがEdgeに存在するが、プロファイルスナップショットデータセットにまだ存在しないことを確認します
- イベントがデータレイクに保存されたことを確認します
