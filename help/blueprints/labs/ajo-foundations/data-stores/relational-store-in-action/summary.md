# 概要

このラボでは、次のアクティビティを実行しました。

- 参照されたスキーマとスキーマ間の表示された関係
- Profile Target Dimensionの設定
- さまざまなワークフローアクティビティを使用して、オーケストレーションされたキャンペーンを構築
- オーディエンスを読み取りアクティビティを使用してオーディエンスを構築し、リレーショナルスキーマ属性と共に使用しました
- キャンペーンでテストモードを使用し、AEP オーディエンスをリレーショナルスキーマと組み合わせて使用する場合の動作を理解した
