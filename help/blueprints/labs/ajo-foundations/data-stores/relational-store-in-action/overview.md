# リレーショナルストアの実際

## ラボの概要

このビデオでは、リレーショナルストアとリアルタイム顧客プロファイルの統合方法について説明します。このラボでは、リレーショナルスキーマの参照、Profile Target Dimensionの設定、オーケストレーションされたキャンペーンの構築とテストについて説明します。

>[!VIDEO](https://video.tv.adobe.com/v/3486539/)

## 学習目標

- スキーマの参照と関係の表示
- Profile Target Dimensionの設定
- さまざまなワークフローアクティビティを使用して、オーケストレーションされたキャンペーンを構築
- オーディエンスを読み取りアクティビティを使用してオーディエンスを作成し、リレーショナルスキーマの属性を使用します
- AEP オーディエンスをリレーショナルスキーマと組み合わせて使用する場合のキャンペーンのテストと動作の把握
