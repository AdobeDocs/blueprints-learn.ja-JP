# 概要

おめでとうございます、ラボが完成しました！ これで、**Adobe Journey Optimizer Decisioning ワークフロー**&#x200B;を構築し、テストできました。

最初に、**オファースキーマ**&#x200B;を拡張し、**実施要件ルール**&#x200B;を作成して、特定のオファーに適格な顧客を制御します。 次に、複数の&#x200B;**オファーアイテム**&#x200B;を作成し、優先順位と頻度の上限を設定して、**オファーコレクション**&#x200B;に整理しました。

次に、**ランキング式**&#x200B;と&#x200B;**選択戦略**&#x200B;を作成して、適格なオファーが決定時にどのように評価および優先順位付けされるかを決定します。 また、**コードベースのエクスペリエンス （CBE） チャネル**&#x200B;を設定して、外部システムがオファー決定を要求および受信できるようにしました。

最後に、**エンドツーエンドの決定フローをテストし**、Adobe Journey Optimizerがプロファイルデータを正しく評価し、決定ロジックを適用し、適切なオファーを返すことを検証しました。
