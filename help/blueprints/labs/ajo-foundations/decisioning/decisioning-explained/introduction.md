# 概要

## 学習目標

このレッスンの終わりまでに、次のことが可能になります。

- AJO Decisioningと従来のOffer Decisioning Engine （ODE）の違い
- このコースで取り上げる構成要素を特定
- コース全体を通して、実践的なシミュレーションに使用する資料を収集します

## 講義

ビデオを始める前にこれらを準備しておくと、今後のすべてのレッスンで使用できます。 準備ができたら、ビデオに進みます。

- 12枚のトランプ（ジャック、クイーン、各スーツのキング）
- 少なくとも12個の付箋紙（間違いを犯した場合に備えて）

次のビデオでは、AJOの決定用語を紹介し、このコースで操作するビルディングブロックと実践カードと付箋のシミュレーションをプレビューします。

>[!VIDEO](https://video.tv.adobe.com/v/3502205/)

## 重要ポイント

- AJO Decisioning （エクスペリエンス決定とも呼ばれます）は、オファーまたは意思決定管理とも呼ばれる、従来のOffer Decisioning Engine （ODE）とは異なる製品です
- 「オファー」（小文字o）は一般的な業界用語です。「オファー」（大文字O）とは、レガシーODE製品を指します。この2つを混同しないでください
- ビルディングブロックは、決定項目XDM、決定項目の作成と実施要件、コレクション、ランキング式、選択戦略、決定ポリシー、決定パッケージの順に説明されます
- コースのシナリオは、架空の電話会社の顧客であるConnection 5Gで、主力の電話ラインナップを開始することです
