# 主なビジネス目標

主なビジネス目標は、企業がデジタルエクスペリエンスへの取り組みを通じて達成しようとしている戦略的成果を定義するものです。 各目的は、Adobe Experience Platformの導入方法と、その成果を達成するためのアプリケーションを説明する1つ以上の[&#x200B; ユースケースパターン &#x200B;](/help/blueprints/use-case-patterns/overview.md)にマッピングされます。

以下の表を使用して、組織に最も関連性の高いビジネス目標を特定し、リンクに従って、各目標をサポートするユースケースパターン、KPI、実装アプローチを確認します。

## 獲得と成長

次の目標は、リーチの拡大と顧客基盤の拡大に重点を置いています。

| 目標 | 説明 | 主要KPI |
| --- | --- | --- |
| [新規顧客の獲得](acquisition-growth/acquire-new-customers.md) | ターゲットを絞った獲得キャンペーン、類似オーディエンス、有料メディアの最適化により、顧客基盤を拡大できます。 | 新規顧客、顧客獲得コスト、見込み顧客/リードコンバージョン |
| [&#x200B; リードジェネレーションの増加](acquisition-growth/increase-lead-generation.md) | フォーム、イベント、コンテンツ、マルチチャネルエンゲージメントを通じて、セールスパイプラインの質の高いリードをより多く生み出します。 | 見込み顧客、リード獲得単価、リードコンバージョン |
| [Web サイトのエンゲージメントの向上](acquisition-growth/increase-website-engagement.md) | 適切なエクスペリエンスを通じて、サイトでの滞在時間、セッションごとのページ、web コンテンツとのインタラクションを改善できます。 | ページ滞在時間、エンゲージメント、コンバージョン率 |

## 収益/収益化

以下の目標は、売上の拡大と取引価値の向上に重点を置いています。

| 目標 | 説明 | 主要KPI |
| --- | --- | --- |
| [&#x200B; コンバージョン率の向上](revenue-monetization/increase-conversion-rates.md) | 購入、サインアップ、フォーム送信など、望ましいアクションを実行した訪問者と見込み顧客の割合を向上させます。 | Cpl、Cpl、Cpl （リード単価） |
| [売上と売上の増加](revenue-monetization/increase-revenue-sales.md) | 最適化されたデジタルチャネル、キャンペーン、カスタマージャーニーを通じて、売上の増加を促進。 | — |
| [&#x200B; クロスセルとアップセルの収益を促進](revenue-monetization/drive-cross-sell-upsell-revenue.md) | 行動や購入履歴にもとづいて、既存顧客に補完的な商品やサービスを宣伝します。 | アップセル/クロスセル %、増分売上、顧客生涯価値 |
| [顧客ロイヤルティと生涯価値の向上](revenue-monetization/increase-customer-loyalty-lifetime-value.md) | ロイヤルティプログラム、特典、パーソナライズされたエンゲージメントを通じて、顧客関係を深化し、長期的な価値を最大化します。 | 顧客生涯価値、リテンション、アップセル/クロスセル % |

## コストと効率性

次の目標は、コストの削減とマーケティング効率の向上に重点を置いています。

| 目標 | 説明 | 主要KPI |
| --- | --- | --- |
| [顧客獲得コストの削減](cost-efficiency/reduce-customer-acquisition-cost.md) | ターゲティング効率を改善し、獲得キャンペーンから既存顧客を除外し、メディア支出を最適化します。 | 顧客獲得コスト、リード獲得単価、効率性 |
| [&#x200B; マーケティング費用とROIの最適化](cost-efficiency/optimize-marketing-spend-roi.md) | ターゲティング、アトリビューション、オーディエンスの抑制、予算配分の改善を通じて、マーケティングのROIを向上できます。 | コストの削減、顧客獲得コスト、売上の増加 |
| [&#x200B; データ品質とガバナンスの改善](cost-efficiency/improve-data-quality-governance.md) | クリーンで完全なコンプライアンスのデータを確保し、正確なターゲティング、無駄の削減、信頼性の高い分析を実現します。 | 効率性とコスト削減 |
| [&#x200B; マーケティングテクノロジーの統合と近代化](cost-efficiency/consolidate-modernize-marketing-technology.md) | 統合されたスケーラブルなプラットフォームに移行することで、ツールの断片化と技術的負債を低減します。 | コスト削減、効率性、市場投入までの時間 |

## エクスペリエンス

次の目標は、顧客ライフサイクル全体でより優れた体験を提供することに重点を置いています。

| 目標 | 説明 | 主要KPI |
| --- | --- | --- |
| [&#x200B; パーソナライズされた顧客体験の提供](customer-experience/deliver-personalized-customer-experiences.md) | 個人の好み、行動、ライフサイクルのステージに合わせて、コンテンツ、オファー、メッセージを調整。 | エンゲージメント、コンバージョン率、顧客満足度（CSAT） |
| [顧客維持率の向上](customer-experience/improve-customer-retention.md) | 価値主導の体験と継続的な関係育成を通じて、既存顧客との関係を維持し、更新する。 | 顧客維持、顧客生涯価値、エンゲージメント |
| [顧客オンボーディングの改善](customer-experience/improve-customer-onboarding.md) | 合理化され、パーソナライズされたウェルカムエクスペリエンスとアクティベーションジャーニーにより、新規顧客の価値創出までの時間を短縮できます。 | エンゲージメント、リテンション、コンバージョン率 |
| [放棄されたカートとジャーニーの復元](customer-experience/recover-abandoned-carts-journeys.md) | タイムリーでパーソナライズされたフォローアップにより、購入、申し込み、登録のフローの途中で離脱したユーザーをリエンゲージできます。 | コンバージョン率、売上増加、エンゲージメント |

## 分析/インサイト

以下の目標は、測定、レポート、データ主導の意思決定の向上に重点を置いています。

| 目標 | 説明 | 主要KPI |
| --- | --- | --- |
| [分析とレポートの改善](analytics-insights/improve-analytics-reporting.md) | 統合ダッシュボードとセルフサービスツールを通じてレポート機能を強化し、より迅速で実用的なマーケティングインサイトを獲得できます。 | 効率性、生産性 |
| [&#x200B; データ主導の意思決定を可能にする](analytics-insights/enable-data-driven-decision-making.md) | セルフサービス型の分析、リアルタイムの顧客インサイト、AIを活用した予測により、戦略を策定できます。 | 効率性、生産性 |
| [&#x200B; マーケティングアトリビューションの改善](analytics-insights/improve-marketing-attribution.md) | マーケティングの顧客接点、チャネル、キャンペーンがコンバージョンと収益に与える影響を正確に測定。 | 効率性と売上の増加 |
